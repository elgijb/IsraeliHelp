# IsraeliHelp — платформа волонтёрской помощи в Израиле

[עברית / Версия на иврите](README.md)

**Код проекта:** 899373 · **Предмет:** Introduction to Web Programming · **Учебный год:** 2026–2027

## Назначение проекта

IsraeliHelp — веб-сайт, который соединяет людей, желающих помогать обществу, с организациями и инициативами в Израиле, которым нужны волонтёры.
Пользователи смогут искать волонтёрские мероприятия по городу, категории и дате, смотреть подробности и записываться.
Администраторы смогут создавать, редактировать и удалять мероприятия и управлять заявками.

## Для кого

- Жители Израиля, которые хотят помогать (школьники, студенты, взрослые).
- Организации и общественные инициативы, которым нужны волонтёры.

## Установка и запуск

### 1. Установка Java (версия 21 или новее)

**macOS:**
```bash
brew install openjdk
echo 'export JAVA_HOME="/opt/homebrew/opt/openjdk/libexec/openjdk.jdk/Contents/Home"' >> ~/.zshrc
echo 'export PATH="$JAVA_HOME/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
java -version
```

**Windows:**
1. Скачать и установить JDK 21+ с сайта https://adoptium.net (при установке отметить «Set JAVA_HOME» и «Add to PATH»).
2. Открыть новое окно PowerShell и проверить: `java -version`

### 2. Установка MySQL

> База данных появится на этапе 2. Здесь будут полные инструкции: создание базы, загрузка тестовых данных, настройка подключения.

### 3. Запуск сайта

Из папки проекта:

**macOS / Linux:**
```bash
./mvnw jetty:run
```

**Windows (PowerShell или CMD):**
```bat
mvnw.cmd jetty:run
```

При первом запуске Maven скачивает нужные библиотеки (нужен интернет).
Когда появится строка `Started oejs.Server` — сайт работает.

### 4. Открытие сайта

Открыть в браузере: **http://localhost:8080**

Остановить сервер: `Ctrl + C` в окне терминала.

### 5. Запуск тестов

```bash
./mvnw test        # macOS / Linux
mvnw.cmd test      # Windows
```

## Известные ограничения

- Проект на этапе 1: есть только каркас (проверочная страница). База данных и функции появятся на следующих этапах.
- Для первого запуска нужен интернет (скачивание библиотек).
- Порт 8080 должен быть свободен.
- Проект рассчитан на запуск через `./mvnw jetty:run`. Библиотека JSTL берётся из плагина Jetty, поэтому для запуска WAR-файла на отдельном Tomcat её нужно добавить в `WEB-INF/lib`.
